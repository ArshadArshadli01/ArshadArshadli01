### 🚀 Featured project: Laravelify

<a href="https://laravelify.cloud"><b>Laravelify</b></a> is a free, open-source, self-hosted deployment panel. One command turns a fresh Ubuntu server into a place where **any app** deploys on `git push`: Laravel, PHP, Node.js, Express, NestJS, React, Vue, Angular, Svelte, Astro, Next.js, Nuxt, and SvelteKit.

- ⚡ Push-to-deploy from GitHub, nginx and SSL, PM2 and Supervisor, per-site PHP and Node versions
- 💾 S3 backups for databases and folders, with restore, look-inside, and download
- 📈 Live traffic, errors, attack detection, uptime, and Telegram alerts
- 🗂️ File manager with trash, web terminal, Cloudflare tunnels, 2FA everywhere

```bash
curl -fsSL https://cdn.laravelify.cloud/install.sh | sudo bash
```
